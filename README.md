כתובת האתר: https://dafi-k.github.io/mevoot-hermon-orders/ (**גרסת בדיקה** - עלתה 22.11.26)

> **עד סיום הבדיקות של שלב 6:** בלשונית "הגדרות" בגיליון, "פתוח להזמנות" = **לא**. כשזה "לא", אפשר לעיין ולבנות עגלה, אבל שליחת הזמנה חסומה בשרת (חוץ מהזמנות בדיקה של הצוות, שלב 4).

## הגיליון והשרת (Google Sheet + Apps Script)
- **הגיליון:** "הזמנות מבואות החרמון" ב-Google Drive של חשבון CONTRAST. הוא מקור האמת למוצרים, למחירים ולמלאי.
- **הקוד:** `apps-script.js` מודבק בגיליון, דרך תוספים ← Apps Script.
- **כתובת השרת (Web app):**
  `https://script.google.com/macros/s/AKfycbynZDBWrzSYNvW6bsdgW3KMWGpIV8maveVTKufv3JilsuD_LYD7d5OxK5h4vuzVMQnMIg/exec`
  - בדיקה מהירה: להוסיף לכתובת `?action=catalog`. אמור להופיע טקסט שמתחיל ב-`{"ok":true`.
- **חשבון:** Workspace, עם מכסה של 1,500 נמעני מייל ביום (כ-375 הזמנות).

### הלשוניות
| לשונית | מה יש בה | מי מעדכן |
|---|---|---|
| מוצרים | שורה לכל מוצר: מחיר, תיאור, מלאי התחלתי, **יתרה**, פעיל | הצוות מעדכן מחירים, תיאורים ו"פעיל". את **היתרה** לא משנים ידנית - רק דרך מסכי הניהול (שלב 5), כדי שכל שינוי יירשם ביומן |
| הגדרות | תקציב, נמעני מייל, סף מלאי נמוך, פתוח להזמנות | הצוות |
| הזמנות / פריטי הזמנה / תנועות מלאי | נכתבות אוטומטית | השרת בלבד |

- כדי **להסתיר מוצר** מהאתר: לשנות את "פעיל" ל"לא".
- "ללא הגבלה" = כן: המוצר מוזמן מהספק, ואין בדיקת מלאי.

### אחרי כל שינוי בקוד ה-Apps Script
1. להדביק את הקוד החדש ולשמור.
2. פריסה ← ניהול פריסות ← עיפרון ← גרסה: **גרסה חדשה** ← פריסה.
3. הכתובת לא משתנה. בלי השלב הזה, האתר ימשיך להריץ את הקוד הישן.

### הגדרות הפריסה (אם יוצרים פריסה מאפס)
- סוג: אפליקציית אינטרנט.
- לבצע בתור: **עצמי**.
- למי יש גישה: **כל אחד**. לא "כל מי שיש לו חשבון Google".
- אם מופיעה השגיאה "אין לך הרשאה להתקשר אל SpreadsheetApp": להריץ מהעורך את `setupSheet`, לאשר את **כל** תיבות ההרשאה, ולפרוס גרסה חדשה.

## האתר (`index.html`)
הזרימה: רישום ← הנחיות ← קטלוג בטאבים ← סיכום ← שליחה ← מסך אישור.

**איך המלאי מוצג:**
- הקטלוג מוצג מיד מעותק שמור: העותק החי האחרון שנשמר בדפדפן, ואם אין כזה, הקובץ `data/catalog-snapshot.json`.
- **עד שהמלאי העדכני מהשרת מגיע, אי אפשר להוסיף לעגלה.** הכפתורים מסומנים "בודק מלאי...".
- המלאי מתרענן כל דקה, וגם במעבר לסיכום או בחזרה ללשונית. אם פריט שבעגלה ירד במלאי, הכמות בעגלה מתעדכנת ומופיעה הודעה.
- אם השרת לא עונה, מופיעה הודעה עם כפתור "נסו שוב", והאתר מנסה שוב אוטומטית.
- **ללקוח לא מוצגות כמויות.** בכרטיס מופיע רק "במלאי", "אזל מהמלאי" (והכפתור נעול) או "בהזמנה מהספק" לפריטים ללא הגבלת מלאי. הכמויות מוצגות רק במסכי הניהול.
- ההגבלה לפי המלאי נשארת: כשמגיעים לכמות המקסימלית, כפתור ה-+ ננעל ומופיעה ההודעה "זו הכמות המקסימלית הזמינה", בלי מספר.

**שולחנות:** בטאב "בנה שולחן" בוחרים רגל, גוון וקוטר. הכמות מוגבלת לנמוך מבין מלאי הרגל ומלאי הפלטה, ורגל שכבר נמצאת בשולחן אחר בעגלה נספרת.

**חריגה מהתקציב:** הפס מתמלא בירוק, בזהב מ-80% ובאדום מעל התקציב. אפשר לשלוח הזמנה בחריגה רק אחרי סימון "אני מאשר/ת".

**פס הקטגוריות:** דבוק למעלה בזמן גלילה.
- מרוחב 700px (טאבלט ומחשב) כל הקטגוריות גלויות, ואם צריך הן נשברות לשתי שורות.
- בטלפון הפס נגלל בהחלקה, עם טשטוש וחץ בקצה שבו יש עוד קטגוריות. הקטגוריה הפעילה נגללת אוטומטית לתוך התצוגה.

**נשמר בדפדפן:** הפרטים והעגלה נשמרים, כך שרענון או סגירה בטעות לא מוחקים אותם. זו נוחות בלבד, ואין שריון מלאי לפני שליחה.

**טאבלט משותף באולם:**
- הכפתור "↺ לקוח חדש" בכותרת מוחק מהמכשיר את העגלה ואת פרטי הצימר, אחרי אישור.
- אחרי שליחה מוצלחת המחיקה נעשית אוטומטית, ומסך האישור חוזר לבד לרישום אחרי 10 דקות.

**מובייל:** נבדק אוטומטית ברוחב 375px וברוחב 768px.
- אין גלילה אופקית.
- אין טקסט קטן מ-12px.
- כל כפתור הוא לפחות 36px, ורוב הכפתורים 44px.

**הגדרות בקוד** (`CONFIG` בראש הסקריפט ב-`index.html`): כתובת השרת, תדירות רענון המלאי, והודעות המלאי ללקוח (`MAX_MSG`, `OUT_MSG`).

### עדכון האתר באוויר
כל שינוי בקבצים עולה לאתר אחרי `git push` (לוקח 1-2 דקות). בדיקה אוטומטית מול האתר החי:
```
cd tools
SITE_URL=https://dafi-k.github.io/mevoot-hermon-orders/ node test-client.js
```

### בדיקה מקומית
```
cd tools
node serve.js            # ואז לפתוח http://localhost:8080
node test-client.js      # בדיקת תצוגה ב-375px וב-768px (דורש את השרת המקומי פועל)
node test-server.js      # בדיקת קוד השרת עם הדמיה של Google
node test-submit.js      # בדיקת שליחה מקצה לקצה: דפדפן + קוד השרת בהדמיה
```

## שליחת הזמנה (שלב 4)
**מה קורה בלחיצה על "שליחה":**
1. האתר שולח לשרת **רק מזהים וכמויות**. השרת מחשב מחירים, סה"כ וחריגה לפי הגיליון בלבד, ומתעלם מכל מחיר שמגיע מהאתר.
2. בתוך נעילה (LockService), כך ששני לקוחות לא יקבלו את אותה יחידה אחרונה:
   - בודק שלטלפון אין הזמנה פעילה (הזמנות "בוטלה" לא נספרות).
   - בודק מלאי. **אם חסר - שום דבר לא נכתב**, והלקוח רואה אילו שורות חסרות (בלי מספרים) וכפתור "עדכון לכמות המקסימלית הזמינה".
   - כותב את ההזמנה, מוריד יתרות ורושם תנועות ביומן.
   - אם הנעילה תפוסה יותר מ-25 שניות: "המערכת עמוסה, נסו שוב בעוד רגע", והעגלה נשמרת.
3. האתר מוריד למכשיר Excel (עם תמונות מוקטנות) ו-PDF בעברית, ומוחק מהמכשיר את העגלה ואת פרטי הרישום.
4. **בקשה נפרדת** שולחת את ה-Excel לשרת: הקובץ נשמר ב-Drive (תיקייה "הזמנות מבואות החרמון - קבצים"), ונשלח מייל לצוות עם CC ללקוח.

**מספרי הזמנה:** `MH-שנהחודשיום-מספר` (למשל MH-261201-014). הזמנת בדיקה: `TEST-...`.

**ניתוק באמצע שליחה:** אם התשובה מהשרת לא הגיעה, הלקוח יכול ללחוץ שוב. אם ההזמנה כבר נקלטה, השרת מזהה את הטלפון ולא נוצרת הזמנה כפולה.

### הזמנות בדיקה (כש"פתוח להזמנות" = לא)
- בלשונית "הגדרות" יש **קוד בדיקה** (נוצר אוטומטית בהרצת setupSheet).
- פותחים את האתר עם הקוד: `https://dafi-k.github.io/mevoot-hermon-orders/?test=הקוד`
- מופיע "מצב בדיקה", וההזמנה נשמרת עם מספר TEST ו"הזמנת בדיקה" בעמודת הערות צוות. המייל מסומן [בדיקה].
- **הזמנת בדיקה מורידה מלאי אמיתי.** אחרי הבדיקה מבטלים אותה (במסכי הניהול, שלב 5), והמלאי חוזר.

### מייל שלא נשלח
- בעמודה "סטטוס מייל" בלשונית הזמנות: "ממתין", "נשלח + תאריך" או "לא נשלח: סיבה" (למשל מכסה יומית).
- שליחה חוזרת: עד שיהיה כפתור במסכי הניהול (שלב 5), להריץ מהעורך את הפונקציה `resendFailedEmails`. היא שולחת שוב כל מייל שלא נשלח, כולל ה-Excel השמור ב-Drive.
- `checkAccount` מהעורך מראה כמה נמענים נותרו היום וכמה נשלחו.

## איך המוצרים מזוהים
לכל מוצר יש **מזהה ייחודי** (עמודה "מזהה"). המזהה הוא המפתח בכל המערכת: עגלה, מלאי, הזמנות ושם קובץ התמונה.
לא משתמשים בקוד או במק"ט כמפתח, כי הם חוזרים על עצמם (P1 הוא גם כיסא פלסטיק וגם פלטה, M1 הוא גם מראה וגם משוטים, ול-OD23/OD27 יש אותו מק"ט).

| לשונית באקסל | דוגמת מזהה |
|---|---|
| כיסאות פלסטיק | `CH-P1` |
| כורסאות | `AR-A1` |
| כיסאות פינת אוכל | `DC1` |
| כיסאות בר | `BC1`, `BC-P16` |
| שולחנות קפה | `CT1` |
| מראות | `MR-M1` |
| רגלי ברזל | `LG-LP1` |
| פלטות | `TOP-P1` (התמונה משותפת לפי גוון: `TOP-black` / `TOP-walnut` / `TOP-natural`) |
| שולחנות חוץ/פנים | `OT1` |
| אחר | `MS-H1`, `MS-M1` |
| ריהוט חוץ | `OD1` ... `OD73` |

**מלאי:** אם עמודת הכמות באקסל ריקה, המוצר מסומן "ללא הגבלה" (כל ריהוט החוץ ומזרן MT1 - בהזמנה מהספק).
